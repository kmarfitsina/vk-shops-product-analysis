# VK Shops: Product & Data Analysis

Исследование вовлечённости (ER) и распространённости интерактивных форматов в сообществах ВКонтакте.

## Выполненные этапы
- [x] **Сбор данных (ETL):** написан парсер на Python (`requests`, VK API `wall.get`), собрано 500+ постов из открытых сообществ (`vk_posts_dataset.csv`).
- [x] **Первичная очистка и расчёт метрик:** отфильтрованы посты с нулевыми просмотрами, рассчитан базовый ER по формуле `(likes + comments + reposts) / views * 100`.

## Промежуточные наблюдения (Checkpoint 1)
1. **Доля интерактива:** в общей выборке из 500 постов лишь ~10.6% (53 поста) содержат признаки интерактива (опросы, конкурсы, призывы к обсуждению), что предварительно подтверждает гипотезу о дефиците формата.
2. **Первичный замер ER:** при грубом сравнении всей выборки медианный ER обычных постов (0.39%) оказался сопоставим с интерактивными (0.31%).
3. **Гипотеза для следующего шага:** необходимо проверить влияние масштаба сообществ (крупные маркетплейсы vs авторские блоги) и отделить нативные опросы от рекламных розыгрышей, чтобы избежать смещения выборки.

## Использованные инструменты
* **Python:** `requests`, `pandas`
* **Источник данных:** VK API (`wall.get`)
* **Среда разработки:** Google Colab
